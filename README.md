# Café Aroma

Sitio web de una cafetería ficticia desarrollado con HTML, CSS y JavaScript.

## Descripción

Proyecto práctico de Git para trabajar con ramas, commits, merges y resolución de conflictos.

## Instalación

Para instalar el proyecto, descarga el repositorio desde GitHub.

Para ejecutar Café Aroma localmente:

1. Descargar los archivos del proyecto.
2. Abrir la carpeta sitio-cafe-aroma.
3. Abrir index.html en un navegador.
